# The Story Nexus 1.2.10

GitHub release title: `The Story Nexus 1.2.10`

Recommended tag: `1.2.10`

## GitHub Release Body

The Story Nexus 1.2.10 adds labelled prose blocks so you can track, manage, and copy prose accepted from SceneBeats.

### What's New

- Accepted prose shows the model and prompt that produced it. **Details** opens the saved generation information and prompt sent.
- Use **Show generation labels** in the editor toolbar to hide or show labels and borders. Your preference is remembered.
- Click a label to select its whole block, then Delete or Backspace to remove it. Undo restores it.
- Use **Remove label** to convert a block to ordinary prose while preserving its text and formatting.
- Use **Disable block** to keep prose in the editor while excluding it from manuscript exports, AI context, new summaries, and word counts. Disabled blocks are read-only until you enable them again.
- Use **Copy text** to copy just a block's prose, including paragraph breaks. Copying also works on disabled blocks.
- An editable blank line between each SceneBeat and its accepted prose gives you space to add your own text.
- Added guided AI setup and retry for Simple Write, a built-in Anima image prompt template, and Markdown copying for lorebook entries.
- Improved lorebook JSON importing and in-app update reliability.

### Upgrade Notes

- Generation labels apply to newly accepted prose; existing ordinary prose remains unchanged.
- Disabled prose stays in story backups and can be re-enabled. Manuscript exports leave it out.
- Previously saved summaries are not rewritten when you disable a block. Regenerate a summary if it contains prose that is now disabled.
