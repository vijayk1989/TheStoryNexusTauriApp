# The Story Nexus 1.2.11

GitHub release title: `The Story Nexus 1.2.11`

Recommended tag: `1.2.11`

## GitHub Release Body

The Story Nexus 1.2.11 adds reusable system prompts and image conversations in Brainstorm, along with new ways to manage and copy your manuscript.

### What's New

- Create **Universal System** prompts and select them separately in SceneBeats and Brainstorm. Reuse the same task prompt with different model instructions. The default **None** keeps existing behavior; preview the resolved prompt before sending.
- Paste images into normal Brainstorm chats or use **Attach image**. Send images with or without a caption, open thumbnails at full size, and ask follow-up questions with a vision-capable model. Large images can be resized automatically.
- Sent text and images appear immediately in your conversation, with a waiting indicator until the reply starts. Failed requests return the message to the input for retry.
- Brainstorm image attachments and drafts are included in Site Backup and restored with their conversations.
- Use **Copy to clipboard** in the **Download** menu to copy the current chapter with formatting and embedded images.
- Accepted SceneBeat prose shows its model and prompt. Inspect generation details, select and delete a whole block, remove its label, or disable it to exclude it from AI context, manuscript exports, and word counts.
- Improved SceneBeat and Brainstorm toolbar alignment and fixed a save timing issue that could discard newly typed SceneBeat commands.
- Includes guided AI setup for Simple Write, Markdown copying for lorebook entries, an Anima image prompt template, and dependency security updates.

### Upgrade Notes

- Existing task prompts remain unchanged. Universal system prompts replace the first system message, or insert one at the beginning when none exists.
- Image conversations require a vision-capable model and normal Brainstorm mode. PNG, JPEG, and WebP are supported, with up to four images per message.
- Site Backup includes images attached to Brainstorm messages or drafts. Other gallery images still need to be downloaded separately. API keys and provider settings remain excluded.
- Generation labels apply to newly accepted prose. Existing ordinary prose remains unchanged. Previously saved summaries must be regenerated if they contain text from a block you later disable.

### Download

Download and run **thestorynexus_1.2.11_x64_en-US.msi** from this release.

Windows may show an unknown publisher or SmartScreen warning. Existing desktop users can also use **Check for Updates** in **Backup & Delete**.
