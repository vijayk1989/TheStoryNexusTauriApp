# The Story Nexus 1.2.12

GitHub release title: `The Story Nexus 1.2.12`

Recommended tag: `1.2.12`

## GitHub Release Body

The Story Nexus 1.2.12 lets you keep writing while Brainstorm works, save reusable prompt drafts, and recover received text from interrupted generations.

### What's New

- Brainstorm responses, regeneration, and agent pipelines continue when you close the panel or switch chats and stories while the app stays open. Chat status indicators show progress, and Stop cancels only the selected chat's task.
- SceneBeat and Brainstorm save received text during generation. Stopped or interrupted responses retain their partial text, including after a reload. Recovered SceneBeat text stays unaccepted so you can review it first.
- Save and load named **Prompt drafts** from SceneBeat and Brainstorm. Append a saved idea to existing input or replace it, and manage story-wide prompt drafts in the **Drafts** panel with rename, copy, and delete actions.
- Unsent Brainstorm text is saved locally per chat and restored when you reopen the app. Saved prompt drafts remain available after deleting their original chat or SceneBeat.
- Drag the divider above Context to resize Brainstorm's response and input areas. The split is remembered, with scrollable input controls for smaller windows.
- Prompt and model selectors have a separate row from input actions. **Resize large Brainstorm images** is now a persistent setting in **Prompt Defaults**.
- Site Backup and story JSON exports include saved prompt drafts and unfinished Brainstorm input.
- Includes dependency security updates.

### Upgrade Notes

- Existing stories and backups remain supported. Prompt drafts are added automatically when you open the updated app.
- Background tasks run while the app remains open. Reloading restores checkpointed text but does not resume the generation request; an abrupt exit can lose the most recently received tokens.
- Named prompt drafts save typed text and prompt/model selections. Attachments, context settings, and generated responses are managed separately.
- Image resizing applies to newly attached images; existing attachments remain unchanged.

### Download

Download and run **thestorynexus_1.2.12_x64_en-US.msi** from this release.

Windows may show an unknown publisher or SmartScreen warning. Existing desktop users can also use **Check for Updates** in **Backup & Delete**.
